## نظرة عامة

### API Endpoints

#### المصادقة
- `POST /api/auth/login` - تسجيل الدخول
- `POST /api/auth/reset-request` - طلب إعادة تعيين كلمة المرور
- `POST /api/auth/reset-password` - تحديث كلمة المرور

#### التقييمات (للطلاب)
- `GET /api/teachers/:gradeLevel/:className` - قائمة المعلمين
- `GET /api/criteria` - معايير التقييم النشطة
- `GET /api/evaluation/status/:studentId/:teacherId` - حالة التقييم
- `POST /api/evaluation/submit` - إرسال التقييم

#### الإدارة - المعايير
- `GET /api/admin/criteria/all` - جميع المعايير (نشطة ومعطلة)
- `POST /api/admin/criteria/add` - إضافة معيار جديد
- `PUT /api/admin/criteria/:id` - تعديل معيار
- `PUT /api/admin/criteria/:id/score` - تعديل الدرجة وإعادة الاحتساب
- `DELETE /api/admin/criteria/:id` - حذف معيار
- `PUT /api/admin/criteria/reorder` - إعادة ترتيب المعايير

#### الإدارة - الإحصائيات
- `GET /api/admin/stats/overview` - الإحصائيات العامة
- `GET /api/admin/stats/by-subject` - إحصائيات المواد
- `GET /api/admin/stats/by-class` - إحصائيات الفصول
- `GET /api/admin/teachers/stats` - إحصائيات جميع المعلمين

#### الإدارة - التقارير
- `GET /api/admin/teacher-report/:teacherId` - تقرير تفصيلي لمعلم
- `GET /api/admin/teachers-all` - جميع المعلمين مع الإحصائيات (للتقارير)
- `GET /api/admin/reports/by-subject` - تقرير المقارنة حسب المادة
- `GET /api/admin/reports/by-class` - تقرير المقارنة حسب الفصل

#### الإدارة - إدارة الطلاب
- `GET /api/admin/students` - جميع الطلاب
- `GET /api/admin/students/:id` - طالب محدد
- `POST /api/admin/students` - إضافة طالب
- `PUT /api/admin/students/:id` - تعديل طالب
- `DELETE /api/admin/students/:id` - حذف طالب

#### الإدارة - إدارة المعلمين
- `GET /api/admin/teachers` - جميع المعلمين
- `GET /api/admin/teachers/:id` - معلم محدد
- `POST /api/admin/teachers` - إضافة معلم
- `PUT /api/admin/teachers/:id` - تعديل معلم
- `DELETE /api/admin/teachers/:id` - حذف معلم
- `POST /api/admin/teachers/:id/classes` - تعيين معلم لفصل
- `DELETE /api/admin/teachers/:teacherId/classes/:classId` - إلغاء تعيين معلم من فصل

#### الإعدادات
- `GET /api/settings` - الإعدادات العامة

## 📊 بنية البيانات

### المستخدمون (users)
- معلومات الحساب: اسم المستخدم، كلمة المرور

- بيانات الطالب: الصف، الفصل، الرقم الطلابي

### خطوات الاستخدام (للطلاب)

1. **تسجيل الدخول**
   - أدخل اسم المستخدم وكلمة المرور
   - انقر على "دخول"

2. **شاشة الترحيب**
   - ستظهر رسالة ترحيب بالطالب
   - انتظر ثانيتين للانتقال التلقائي

3. **اختيار المعلم**
   - ستظهر قائمة بجميع معلمي الفصل
   - كل بطاقة تحتوي على اسم المعلم والمادة
   - انقر على "ابدأ التقييم"

4. **تقييم المعلم**
   - قيّم كل معيار من 1 إلى 10 نجوم
   - يجب تقييم جميع المعايير الستة
   - انقر على "إرسال التقييم"

5. **التأكيد**
   - ستظهر رسالة نجاح
   - يمكنك العودة لتقييم معلم آخر

### خطوات استخدام لوحة الإدارة

1. **تسجيل الدخول كمسؤول**
   - اسم المستخدم: `admin`
   - كلمة المرور: `admin123`

2. **الصفحة الرئيسية**
   - عرض الإحصائيات العامة (الطلاب، المعلمين، التقييمات)
   - 4 بطاقات رئيسية للوصول السريع

3. **إدارة معايير التقييم**
   - **إضافة معيار**: انقر "إضافة معيار جديد"
   - **تعديل معيار**: انقر زر "تعديل" (الأزرق)
   - **تعديل الدرجة وإعادة الاحتساب**: انقر زر "الحاسبة" (البرتقالي)
     - سيتم إعادة احتساب جميع التقييمات تلقائياً
     - مثال: تغيير من 10 إلى 5 → جميع الدرجات × 0.5
   - **تفعيل/تعطيل**: انقر الزر الأصفر
   - **حذف**: متاح فقط للمعايير التي لا توجد لها تقييمات

4. **التقارير والرسوم البيانية**
   - رسوم بيانية بالمواد والفصول
   - عرض أفضل 3 معلمين
   - جميع الرسوم تستخدم Chart.js
   - **أزرار تصدير PDF**:
     - تصدير التقرير الشامل (جميع المعلمين)
     - تصدير مقارنة المواد
     - تصدير مقارنة الفصول

5. **إدارة المعلمين**
   - عرض جميع المعلمين مع إحصائياتهم
   - التقرير التفصيلي لكل معلم:
     - رسم Radar للأداء حسب المعايير
     - الأداء حسب الفصول
     - جدول تفصيلي بالنسب المئوية
     - التقييمات (ممتاز، جيد جداً، جيد، مقبول، ضعيف)
     - **زر تصدير PDF** لتقرير المعلم
     
6. **إدارة الطلاب والمعلمين CRUD**
   - واجهات كاملة لإضافة/تعديل/حذف الطلاب
   - واجهات كاملة لإضافة/تعديل/حذف المعلمين
   - تعيين المعلمين للفصول
   - بحث وفلترة متقدمة
   
7. **نظام الإشعارات Toast**
   - إشعارات احترافية لجميع العمليات
   - تصميم Glass effect
   - 4 أنواع: نجاح، خطأ، تحذير، معلومة
