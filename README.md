# معلمي 2025 - نظام تقييم المعلمين

## نظرة عامة
نظام إلكتروني متكامل لتقييم المعلمين من قبل طلاب المرحلة المتوسطة. يتميز بواجهة سهلة الاستخدام، أيقونات ثلاثية الأبعاد جذابة، ونظام تقارير شامل.

## 🌐 الروابط

**Production URL**: https://3000-ieciq5kediojedjz87yvm-b237eb32.sandbox.novita.ai

### API Endpoints
- **تسجيل الدخول**: `POST /api/auth/login`
- **إعادة تعيين كلمة المرور**: `POST /api/auth/reset-request`
- **قائمة المعلمين**: `GET /api/teachers/:gradeLevel/:className`
- **معايير التقييم**: `GET /api/criteria`
- **إرسال التقييم**: `POST /api/evaluation/submit`
- **تقارير المعلمين**: `GET /api/admin/teacher-report/:teacherId`

## 📊 بنية البيانات

### المستخدمون (users)
- معلومات الحساب: اسم المستخدم، كلمة المرور
- البيانات الشخصية: الاسم الكامل، البريد الإلكتروني، الهاتف
- بيانات الطالب: الصف، الفصل، الرقم الطلابي
- نوع المستخدم: طالب / مسؤول

### المعلمون (teachers)
- البيانات الأساسية: الاسم، المادة، التخصص
- معلومات الاتصال: البريد، الهاتف
- الرقم الوظيفي وصورة المعلم

### التقييمات (evaluations)
- ربط الطالب بالمعلم
- الدرجة لكل معيار
- بيانات الفصل والمادة
- السنة الأكاديمية

## 🚀 تعليمات الاستخدام

### حسابات تجريبية

#### للطلاب
- **الفصل 1أ**:
  - `student1` / `pass123` - عبدالرحمن أحمد الزهراني
  - `student2` / `pass123` - عمر محمد العمري
  - `student3` / `pass123` - فيصل خالد المطيري
  - `student4` / `pass123` - سارة علي السبيعي
  - `student5` / `pass123` - مريم سعد الدوسري

- **الفصل 1ب**:
  - `student6` / `pass123` - يوسف فهد الشمري
  - `student7` / `pass123` - منصور ناصر القرني
  - `student8` / `pass123` - لمى عبدالله الحربي
  - `student9` / `pass123` - ريم محمد الغامدي
  - `student10` / `pass123` - نواف عبدالعزيز العتيبي

#### للإدارة
- `admin` / `admin123` - مدير النظام

### خطوات الاستخدام (للطلاب)

1. **تسجيل الدخول**
   - أدخل اسم المستخدم وكلمة المرور
   - انقر على "دخول"

2. **شاشة الترحيب**
   - ستظهر رسالة ترحيب بالطالب
   - انتظر ثانيتين للانتقال التلقائي

3. **اختيار المعلم**
   - ستظهر قائمة بجميع معلمي الفصل
   - كل بطاقة تحتوي على اسم المعلم والمادة
   - انقر على "ابدأ التقييم"

4. **تقييم المعلم**
   - قيّم كل معيار من 1 إلى 10 نجوم
   - يجب تقييم جميع المعايير الستة
   - انقر على "إرسال التقييم"

5. **التأكيد**
   - ستظهر رسالة نجاح
   - يمكنك العودة لتقييم معلم آخر

## 🔧 التكنولوجيا المستخدمة

### Backend
- **Hono Framework** - إطار عمل خفيف وسريع
- **Cloudflare Workers** - معالجة على الحافة
- **Cloudflare D1** - قاعدة بيانات SQLite موزعة عالمياً

### Frontend
- **Tailwind CSS** - تصميم سريع ومرن
- **Font Awesome** - أيقونات احترافية
- **Axios** - طلبات HTTP
- **Chart.js** - رسوم بيانية (جاهز للاستخدام)
- **Vanilla JavaScript** - بدون dependencies إضافية

### Development Tools
- **Vite** - بناء سريع
- **TypeScript** - أمان الأنواع
- **Wrangler** - نشر Cloudflare
- **PM2** - إدارة العمليات

## 🛠️ التطوير المحلي

### متطلبات التشغيل
- Node.js 18+
- npm أو yarn
- حساب Cloudflare (للنشر الإنتاجي)

### تشغيل محلي
```bash
# تثبيت الاعتماديات
npm install

# بناء المشروع
npm run build

# تهيئة قاعدة البيانات
curl -X POST http://localhost:3000/api/init-db

# تشغيل السيرفر المحلي
npm run dev:sandbox
# أو باستخدام PM2
pm2 start ecosystem.config.cjs

# فتح المتصفح
http://localhost:3000
```

### إعادة تعيين قاعدة البيانات
```bash
npm run db:reset
```
