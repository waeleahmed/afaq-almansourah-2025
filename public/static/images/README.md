# الشعار والصور

## شعار المجمع التعليمي (logo.png)

**المطلوب:** ضع شعار المجمع التعليمي الخاص بك هنا باسم `logo.png`

**المواصفات الموصى بها:**
- الحجم: 512x512 بكسل أو أكبر (مربع)
- التنسيق: PNG (مع خلفية شفافة)
- الحجم: أقل من 200 كيلوبايت

**الاستخدام:**
سيظهر الشعار في:
- صفحة تسجيل الدخول (أعلى الصفحة)
- رأسيات التقارير المُصدَّرة
- صفحة الإعدادات

إذا لم يتم إضافة الشعار، سيظهر رمز افتراضي بدلاً منه.
